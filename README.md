# 🌻 A Little Universe for Nikita

> *"For the girl who loves sunflowers 🌻"*

An emotional, cinematic, editorial-quality interactive digital greeting card handcrafted with love especially for **Nikita**. Designed with the aesthetics of a vintage botanical journal, pressed flowers, warm golden sunlight filtering through sheer curtains, and cream-colored handmade paper.

---

## ✨ Features

- **The Blooming First Impression**: A warm ivory opening scene with a blooming SVG sunflower and floating golden petals that gently transition into the card.
- **The Hero (Nikita's Portrait)**: Nikita's authentic photograph mounted on a fine botanical journal frame with washi tape, pressed floral doodles, and the handwritten note *"our little ray of sunshine ☀️"*.
- **The Heartfelt Letter**: A cream stationery letter with a golden wax seal and heartfelt words.
- **Interactive Sunflower Garden**: Five illustrated sunflowers of varying heights swaying gently in the breeze. Clicking each one blooms the flower, triggers golden particle bursts, and reveals a personal message.
- **Secret Keepsake Envelope**: An interactive 3D folding envelope labeled *"One last little thing..."* that unfolds to reveal an emotional reminder to *"Stay golden, Nikita"*.
- **Closing Scene**: A majestic sunflower and an interactive *"Send a little sunshine ☀️"* button that reveals pocket-sized sunshine for cloudy days.
- **Global Persistent Signature**: Fixed floating badge with the exact words **"Love you, mah baby ♡"**, featuring a cute interactive petal and heart burst on click!
- **Soothing Acoustic Melodic Synth**: Royalty-free, 100% self-contained Web Audio API harp/music box ambient melody with a sound-wave toggle.

---

## 🛠️ Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Lucide React** (Botanical & UI icons)
- **Canvas Confetti** (Golden petal & heart bursts)
- **Web Audio API** (Gentle acoustic chime melody)

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/priyanshukrr/flowers.git
cd flowers
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
